## 8.1 六大门禁

```
Gate A·禁用词替换：
  情态类→仿佛/好像/犹如/宛若/一丝/一抹/些许/隐约
  动作类→深吸一口气/缓缓/不禁/微微/轻轻/淡淡
  表情类→眼中闪过/嘴角勾起/眉头微皱/眉眼低垂
  心理类→心中一动/心头一震/心下了然/心底泛起/不由得
  判断类→不容置疑/不易察觉/显而易见/毫无疑问
  过渡类→突然/瞬间/不由自主/情不自禁/自然而然
  替换原则：禁用词→具体动作/细节描写

Gate B·句式去套路：
  "XX说道"→用动作替代（60%+无标签）
  "……，带着……"万能状语→独立短句
  "他/她知道……"→用行为展示

Gate C·心理描写外化：
  "他很紧张"→"他的手在抖"
  "她很愤怒"→"她一把掀翻了桌子"

Gate D·节奏打碎：
  打断连续排比句
  长句拆短句，段落长短交错
  偶尔用不完整句

Gate E·对话去腔调：
  加入"嗯""哦""行吧""靠""嘶"
  角色可以答非所问
  删掉解释性对话

Gate F·结尾去升华：
  删总结性语句（"他明白了""这一刻……"）
  用动作/场景收尾（"他把烟掐了，回屋睡觉。"）
```

## 8.2 三刀流（番茄爆文特化）

```
第一刀·斩逻辑链：删因为/所以/为了/试图/由于
第二刀·砍形容词：用生理反应替换（愤怒地→抄起烟灰缸砸过去）
第三刀·拆长句：每段不超过3行，每句不超过15字
```

## 8.3 八类必查问题

```
① 解释腔：删掉替读者解释意义的句子
② 作者报账：让账本/菜单/对白自己报账
③ 镜头脚本语言：恢复人物动作链
④ 先果后因：按时间顺序重排
⑤ 主语断裂：一个句群只服务一个动作中心
⑥ 空泛情绪：换成身体反应/动作延迟/物件误碰
⑦ 模板化AI句式：删"不是X而是Y""这意味着""仿佛/好像连用"
⑧ 段尾金句病：段尾要有功能差异，不每段都落判断
```

## 8.4 AI味分级处理

```
轻度（禁用词≤5处/千字）→ Gate A+B
中度（禁用词6-15处/千字）→ Gate A+B+C+D
重度（禁用词>15处/千字）→ 完整六门禁+三刀流+八类必查
```

## 10. AI 味打分公式

```
AI味分 = Σ(DeepSeek A级命中 × 3)
       + Σ(DeepSeek A-级命中 × 2)
       + Σ(patterns S2 命中 × 2)
       + Σ(patterns S3 命中 × 1)
       + Σ(意象词 cat22 命中 × 1.5)
       − Σ(白名单豁免命中 × 1)

阈值：
  分值 ≥ 6  => 触发拦截，必须改写
  分值 ≥ 3  => 提示人工复核
  分值 < 3  => 通过
```

每条命中自带 `fix_direction`（修复方向），直接作为给作者的改写指引输出。

| **L1** | 句式正则层 | DeepSeek 734 句式 + R1-R11 + Gate + qu-ai-wei 51 条 | deepseek_ai_sentence_blacklist.json / ai_flavor_patterns.json | A 级命中即判 AI 味 |
| **L2** | 人感禁令层 | em-dash / "像"字 / 文言腔 / 拟人 / 网文黑名单 | webnovel_blacklist.json | 命中即判 AI 味 |
| **L3** | 方法论语义层 | 真人门检 / 过度消毒 / AI 不敢写 / 万能动词 / 翻译腔 | E1_tone.md §L3 三节 | 命中即扣 S2 |
| **L4** | 量化指标层 | 困惑度 / TTR / 可读性 / 句长方差 | scripts/d1_tone_audit.py | 越阈值即扣 S2 |

> **关键**：脚本抓 L1/L2/L4（正则+量化），专家判 L3（语义）。专家必经 L1-L4 全部 findings 复核，但**只能补充语义判断，不能上调硬门禁**。

### 11.2 L2 人感禁令层（5 类硬禁令）

| 禁令 | 检测点 | 命中即抓 | 豁免条件 |
|:-----|:-------|:---------|:---------|
| **em-dash 滥用** | 单章 ≥3 处 `——` | 抓 | 角色口音/古风正文豁免 |
| **"像"字句** | 单章 ≥5 处 `像/如/似/若` | 抓 | 比喻为关键修辞手段时酌减 |
| **文言腔** | 四字短语堆砌/对仗工整 | 抓（叙述段） | 古风正文/古人角色声口豁免 |
| **过度拟人** | "风在低语/夜色吞噬" | 抓 | 童话/奇幻氛围豁免 |
| **网文黑名单** | 见 `webnovel_blacklist.json` | 抓 | 在白名单 `context_genres` 内豁免 |

### 11.3 L3 方法论语义硬门禁三节（最关键的"人味"判据）

> L3 三节是 E1 专家的语义判据——脚本抓不到，必须人工读。命中即扣 S2。

#### 一、真人门检判据（审稿第一步）

**先判断"这段文字是不是真人写的"**。真人强信号（命中任何一条，**优先判"不改"**）：

- **自纠/犹疑/填充语气词**："哦不对""等等""呃""那个""就是说"
- **浓厚地域词/方言语素**："啥""咋""俺""侬""阿拉""咩""咯""噻"
- **meta-irony/自嘲**："我这个人""别提了""一言难尽""你说气人不气人"
- **具体到只有这个人/这件事的细节**："我姥姥""我二舅""我们村""我高中同桌"
- **已知作家的可辨识口吻**
- **浓厚访谈/对话实录特征**："他顿了顿说""她笑了笑""他沉默了半天"

> **判断不准时，宁可判"真人"不改**。残留 AI 腔可以再改一轮，改坏真人的声口是不可逆的。

#### 二、过度消毒反制判据（硬门禁，命中即扣 S2）

去 AI 腔有一个反向陷阱：把 AI 腔改成"AI 假装正常人"。
**表现**：不用流行语、不用 emoji、句式工整、语气克制、永远客观中立——读起来"没毛病"，但没有任何记忆点。

**三类必须保留的毛边**（至少一处）：

1. **个人化表达**："我""我觉得""说实话""老实说"
2. **具体的感受/真实的复杂**："心里一酸""眼眶发热""手心出汗"
3. **圈层/语境特有表达**：方言、行话、圈内黑话

**判定**：终稿"正确但死气沉沉"——三类毛边全无 → 标 S2 过度消毒。

#### 三、AI 不敢写测试判据（硬门禁，命中即扣 S2）

**终稿底线自检**：这段话里有没有一句是 AI 不敢写的？

**五类"AI 不敢写"信号**（哪怕只出现一处即合格）：

1. **自嘲/自黑**："我真笨""我这人就没""我当时竟然"
2. **承认不确定/记不清**："我记不清了""我也说不准""好像是的"
3. **冒犯性/不合时宜的观点**："我就是讨厌""这话难听""管他呢"
4. **身份降格/私人暴露**："我当时狼狈""我当时怂""我当时哭"
5. **别人不会知道的具体细节**："我姥姥""我二舅""我高中同桌"

**判定**：全章五类信号=0 → 标 S2"太干净，疑似 AI 假装正常人"。

## 12. 6 类逐句审查判据（v6.1 新增）

> 来源：novel-audit-v6.0.0 · `E1_tone.md` v5.6.1
> E1 专家**必经逐句审查**——对全文每句逐一阅读并标记 passed/failed，不得抽样。覆盖六类非常规写作风格。

### 12.1 文言文表达（叙述段 S3，对白放宽）

**判据**：四字短语堆砌/对仗工整/书面化腔调出现在叙述段。

| 文言腔（要抓） | 人话（放行） |
|:---|:---|
| 山峦叠嶂，云雾缭绕，宛若仙境 | 山很高，云很厚，看着像画里的 |
| 心旷神怡，宠辱偕忘 | 他心里松了一下，什么烦心事都忘了 |
| 此乃天赐良机，不可错失 | 这机会不抓住就是傻子 |

**豁免**：角色本身是古代人/修仙者且作者有意用文言腔塑造声口；引用古籍/功法口诀/诗词。

### 12.2 电报式简略句式（6 类变体图谱）

> 脚本能抓"≤8 字连续 3 句无连接词"，但以下 6 类变体全部漏检，必须人工逐句排查。

| 变体 | 判据 | 抓 | 放行 |
|:-----|:-----|:---|:-----|
| **A 省略主语连环** | 连续 3 句以上省略主语 | 走进屋子。看见桌上有一封信。拆开看了。脸色变了。 | 他走进屋子，看见桌上有一封信。拆开看了，脸色变了。 |
| **B 虚词清零** | 连续 3 句无"了/着/的/地/得/也/还/又/就/才/再/都/很/太/更/最" | 他转身。脚步快。呼吸急。汗从额头滑下。 | 他转身就走，脚步快了起来，呼吸也急了，汗从额头滑下来。 |
| **C 名词孤岛** | 单句只有名词短语，连续 2 个以上 | 夜。风。灯。一个人。 | 夜里起风了，路灯下站着一个人。 |
| **D 对话电报** | 对白连续 3 句 ≤10 字无语气词 | "你来了。""嗯。""坐。""好。" | "你来了？"他没抬头。"坐吧。""……行。" |
| **E 心理电报** | 内心独白连续 3 句 ≤12 字无因果递进 | 不对劲。有问题。得走。现在就走。 | 不对劲。他想。这事儿有问题，得走，现在就走。 |
| **F 动作电报** | 动作场景连续 4 句 ≤12 字无身体感受 | 他冲过去。挥刀。砍中。敌人倒了。 | 他冲过去挥刀，刀刃砍进肉里的震动从手腕传到肩膀，敌人倒了。 |

**关键区分**：短句本身没问题——情绪重锤需要短句。问题是**连续短句缺过程流**，像发电报不像人说话。

**放行场景**：
- 情绪重锤（单句锚点）："完了。"——放行
- 角色寡言对白："山上。"（老头两字回答是性格）——放行
- 场景锚点："青衫镇。"（独立一行做场景标识）——放行
- 快节奏打斗交替："他闪。他挡。他退。"——交替使用放行，全章统一则抓

### 12.3 比喻/排比密度（S3）

**判据**：单句内比喻≥2 或排比≥3 项。

### 12.4 解说腔（S3，与段落功能二分法互补）

**判据**：上帝视角替角色下判断，句内无角色当下感知。

### 12.5 节奏断点（S4）

**判据**：长句突然切短句（或反向）无过渡，读起来顿挫感过强。

### 12.6 AI 套话残留（S3）

**判据**：语义层面判断"这句话像不像 AI 写的"，不限于脚本正则覆盖的 734 条。
**典型信号**：过度工整的排比、万能动词（激发/实现/达成）、翻译腔（"在当今社会"）、空洞总结（"这就是人生"）。

### 系统面板豁免

【】包裹的系统面板/图鉴 UI 不纳入逐句审查范围。

### 对白句放宽规则

对白句（引号内）的文言文/电报式句式判定标准放宽——角色说话可以短促/文绉绉，只要符合人设。例如修仙者角色说"此乃何物"不算文言腔，是人物声口。

## 13. 段落功能二分法（解说腔/电报体的真正判据）

> 这是最锋利的武器，专治**脚本抓不到的两类漏检**。
> **问题背景**：脚本用正则抓"解说句"和"≤8 字+无连接词"的电报体。于是——整段都是解说（不踩句式）→ 脚本漏；三个 12 字短句堆砌（超 8 字或带个"而/但"）→ 脚本漏。

**你必须逐段问一个问题：这段是替角色总结变化，还是在写角色当下的反应？**

| | 解说腔（上帝视角，要抓） | 人感（角色当下，放行） |
|:---|:---|:---|
| **段落功能** | 事后总结、替读者概括变化、上帝视角归因 | 正在经历此刻的角色身体反应 |
| **判别口诀** | **找不到一个"正在经历此刻的角色身体"** | **能找到**（他感到疼/他听见/他手心出汗） |
| **典型样貌** | "他的实力已经今非昔比""这一切让他成长了""他不再是那个少年" | "他喉咙发紧""后颈的汗毛竖了起来""耳朵里嗡嗡作响" |
| **节奏特征** | 短句切碎但无"等待→动作→感受→判断"的过程流，像发电报 | 短句有先后、有因果、有身体节拍 |

**操作**：对每段叙述（非对白），先定位"这段在身体层面写没写角色此刻的感知"。没写、只在做总结/归因/暗示 → 判解说腔（S3 复核后升 S2）；短句堆砌但缺过程流 → 判电报体。

## 14. 逐句审查输出格式（v6.1 新增）

> 每章 E1 审查完毕后必须产出 `sentence_review` 字段，含每句审查结果。

```json
{
  "sentence_review": {
    "reviewer": "E1",
    "review_time": "2026-07-25T10:30:00Z",
    "total": 156,
    "passed": 142,
    "failed": 14,
    "pass_rate": 0.910,
    "failures": [
      {
        "sentence_idx": 23,
        "sentence": "他感到一阵莫名的悲伤涌上心头。",
        "type": "AI套话残留",
        "severity": "S3",
        "fix": "外化为身体反应：他喉咙发紧，眼眶一下子热了起来。"
      }
    ]
  }
}
```

**纪律**：
- 逐句审查 S2 级问题必须同时进入 `findings` 数组参与硬门禁判定
- 不得因章节长而抽样或跳读
- `pass_rate < 0.85` 的章节整体判 S2，触发深度复审
