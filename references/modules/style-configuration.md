# 风格配置系统（style-configuration）

> 来源：集成自 novel-audit-v6.0.0 · `style_dimensions.json`（v1.4）+ `intent_router.json`（v1.4）
> 触发词：风格配置、写作风格、定调、题材路由、风格维度、风格统一、声口统一、风格漂移、定档风格、风格档、风格配置文件、统一调性、风格一致性

## 1. 模块定位

**「先把风格定下来，再写一字正文。」**

风格配置是写作前的"调性档"——8 个维度组合出全书统一风格，7 大题材路由出对应权重配置。**风格漂移是网文最大隐患之一**：前 10 章冷峻克制，第 11 章突然煽情，读者会立刻出戏。

本模块负责：
1. 写作前生成 `style_config.json`（8 维度风格档案）
2. 题材路由（7 大题材触发关键词→权重配置）
3. 写作中校验风格一致性（每章对账）
4. 风格漂移预警（与 style_config 偏离即告警）

### 2.3 风格档案 schema（style_config.json）

```json
{
  "version": "1.4",
  "book_id": "my-novel-001",
  "genre": "都市",
  "style_profile": "电影感档",
  "dimensions": {
    "writing_style": "电影感",
    "tone": "克制",
    "pov": "第三人称限知",
    "tense": "过去时",
    "pace": "张弛交替",
    "scene_density": "中等密度",
    "dialogue_style": "简练锋利",
    "description_density": "适度细节"
  },
  "lock_strategy": {
    "lock_until_chapter": 0,
    "allow_drift_after": 30,
    "drift_threshold": 2
  }
}
```

**字段说明**：

| 字段 | 含义 |
|:-----|:-----|
| `style_profile` | 风格档位名（参考 2.2 速查表，可自定义） |
| `dimensions` | 8 维度配置（每维度单选） |
| `lock_until_chapter` | 前 N 章锁定不允许漂移（建议前 10 章） |
| `allow_drift_after` | 第 N 章后允许小幅漂移（成长需要） |
| `drift_threshold` | 允许漂移的维度数（建议 2，超过即告警） |

## 4. 风格一致性校验流程

### 4.1 写章前·读取风格档案

```
1. 读取 style_config.json
2. 提取 8 维度配置
3. 注入到本次写作的 prompt 上下文
   ├─ writing_style → 决定句式倾向（古典/现代/白话/...）
   ├─ tone → 决定语气调性
   ├─ pov → 决定视角选择
   ├─ tense → 决定时态
   ├─ pace → 决定长短句节奏
   ├─ scene_density → 决定场景切换频率
   ├─ dialogue_style → 决定对白声口
   └─ description_density → 决定描写详略
```

### 4.2 写章后·风格漂移检测

```
对每章用脚本/专家做风格识别：
1. 实测 8 维度（基于章节正文自动识别）
2. 与 style_config.json 对账
3. 漂移维度数 > drift_threshold → 告警
4. 前 lock_until_chapter 章内任何漂移 → 告警（不允许）
```

### 4.3 风格漂移 5 大典型

| 漂移类型 | 表现 | 原因 | 修复 |
|:---------|:-----|:-----|:-----|
| **语气漂移** | 前 10 章冷峻，第 11 章突然煽情 | 作者情绪化写作 | 回顾 style_config.tone，强制回调 |
| **视角漂移** | 三限知突然切上帝视角 | 设定倾倒需要 | 改为角色感知到的信息 |
| **节奏漂移** | 紧凑突然变舒缓（或反向） | 章节功能变化允许，但需过渡 | 加过渡段 |
| **对白漂移** | 简练锋利突然变情感外露 | 角色情绪爆发合理，但声口不能变 | 保留声口，调情绪词 |
| **描写漂移** | 极简白描突然浓墨重彩 | 重点场面需要加强 | 允许，但需有节奏 |

### 4.4 风格档案变更纪律

- **前 10 章锁定**：不允许任何风格漂移（建立读者预期）
- **10-30 章微调**：允许 drift_threshold=2 的漂移（成长需要）
- **30 章后调整**：允许主动调整 style_config，但必须落盘并说明原因
- **禁止隐式漂移**：任何风格变化必须显式更新 style_config.json，不得在写作中无声明漂移

## 5. 跨模块联动

| 联动模块 | 联动点 |
|:---------|:-------|

| **descriptive-craft** | 描写密度受 description_density 维度约束 |
| **pacing-dynamics** | 节奏档受 pace 维度约束 |
| **narrative-weaving** | POV 切换受 pov 维度约束 |
| **anti-ai-polish** | 风格档案决定 L2 人感禁令的豁免条件（如古风正文豁免文言腔） |
| **platform-rules** | 平台适配影响 style_profile 推荐（番茄推流→爽文爆爽档） |
