# Demo: 番茄爆文第一章 + v6.2 工具链输出示例

> 本文件演示 v6.2 工坊对同一章节的多工具协同输出：正文生成 → 字数/AI味分析 → 风格档案 → MBTI 声线 → 温度词分析 → 五专家审计 → 16 维事实快照。所有数据均为示例，可复现。

---

## 1. 输入

```
写番茄爆文第一章。主角：被裁员的中年程序员，回家路上发现世界变了
```

## 2. 输出节选（正文）

标题：《刚被裁，全人类进了数据副本》

第一章

手机震了三下。

陈默看了一眼手机，是HR发来的离职证明。他锁屏，把手机塞回口袋。

今天第三家公司了。

三个月，投了76份简历，面试23家，全部卡在「年龄超35岁」这一条上。

他站在天桥上往下看。

（正文完整版见 [sample-chapter.md](sample-chapter.md)，约 2000 字）

<sub>↑ 300字内入题，短句口语化，无AI味禁用词，章首不用时间词——符合 core-writing 铁律</sub>

## 5. MBTI 16 型对白声线档案（dialogue-mastery · v6.2 集成）

| 角色 | MBTI | 节奏 | 词汇偏好 | 反应模式 | 典型口头禅 |
|:-----|:-----|:-----|:---------|:---------|:-----------|
| 陈默 | **ISTJ** | 慢/稳/短 | 准确/事实/数据 | 先思考后开口，不轻易表态 | "按规定"/"事实是" |
| 林晚 | **ENFJ** | 中/感染 | 价值/愿景/我们 | 鼓舞他人，富有感染力 | "我们一起"/"相信" |

**E3 专家声线判定 4 步**：
1. 读取 characters.json 中 MBTI → ISTJ / ENFJ
2. 对照 16 型速查表提取声线特征
3. 逐句审查：
   - 陈默："刚被裁。"（短/事实/不解释）→ 符合 ISTJ ✅
   - 林晚："我们公司好像在招。"（关系导向/主动）→ 符合 ENFJ ✅
4. 偏离即标 S2 → 本章 0 偏离 ✅

**4 气质组对照**：SJ 传统派（陈默）vs NF 理想派（林晚）—— 天然产生"务实 vs 鼓舞"的对话张力。
